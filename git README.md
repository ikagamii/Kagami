## What is Kagami?

**Kagami** (鏡, Japanese for *mirror*) puts your phone's screen on your Windows PC or Mac, exactly as it looks in your hand. It is built for mobile gamers, streamers, YouTubers and educators who need a setup that simply works: no lag, no blur, no lost recordings.

Kagami works with **iPhone and iPad** today, over **USB or Wi-Fi**, with **nothing to install on the phone**.

## Features

| | |
|---|---|
| 🎯 **Full quality, up to 120 Hz** | Full resolution, smooth on ProMotion devices |
| ⚡ **Ultra-low latency** | The whole path, from capture to display, measured and tuned |
| ⏺️ **One-click recording** | MP4 or MOV, game sound and mic mixed or as separate files |
| 🛡️ **Crash-safe recording** | Protected every 2 seconds inside the app; you always keep one complete file |
| ⏪ **Instant replay** | Save the moment after it happens |
| 🎙️ **Studio-quality mic clean-up** | Clean voice without extra software |
| 🎥 **Clean OBS feed** | Full-quality output for OBS, even when the window is hidden |
| 🙈 **Privacy mode** | Hide the screen with one key |

## Requirements

- **Windows:** Windows 10 or 11 (64-bit)
- **Mac:** Apple silicon, macOS 26 or later
- **Phone:** iPhone or iPad
